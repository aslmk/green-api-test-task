## О задании

В рамках задания разработано веб-приложение для работы с API GREEN-API,
позволяющее пользователю указать параметры подключения к собственному
инстансу и выполнить следующие методы:

- `getSettings`
- `getStateInstance`
- `sendMessage`
- `sendFileByUrl`

Ответы API отображаются непосредственно на странице.

## Технологии

- Java 21
- Spring Boot
- HTML
- CSS
- JavaScript
- Docker

## Использование

Для работы приложения необходимо указать:

- `idInstance`
- `ApiTokenInstance`

полученные в личном кабинете GREEN-API.

После подключения инстанса пользователь может последовательно выполнять
доступные методы и просматривать ответы API на странице.
